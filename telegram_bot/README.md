# ⚡ Telegram Username Radar Bot

Telegram-бот на базе **aiogram 3.x** и **Pillow** для поиска свободных, эстетичных и редких юзернеймов из **5 и 6 символов**, аналитической оценки их стоимости по стандартам Fragment (TON / USD / ₽) и генерации дизайнерских карточек.

---

## 🌟 Возможности бота

1. **Поиск свободных юзернеймов (5 или 6 символов)**:
   - Генерация благозвучных, гармоничных тегов по фонетическим формулам.
   - Проверка доступности в реальном времени в сети Telegram.
   - Расчёт рыночной капитализации: стоимость в TON, долларах ($) и рублях (₽), показатель гармонии и редкости.

2. **Дизайнерские карточки (Pillow)**:
   - **Карточка находки**: стильный баннер в тёмной неоновой стилистике с большим `@username`, статусом `AVAILABLE`, плашками длины, стоимости в TON/$ и редкости.
   - **Баннер профиля**: при открытии раздела «Профиль» над сообщением формируется персонализированная карточка со статусом, аватаром, ID и шкалой запросов.

3. **Тарифы и ограничения**:
   - **Базовый (Free)**: 2 бесплатных запроса для ознакомления.
   - **Премиум (Безлимит)**: неограниченное число поисков, золотой статус и снятие всех лимитов.

4. **Активация Премиума**:
   - Кнопка активации демо-доступа в 1 клик прямо в боте.
   - Встроенные промокоды: `PREMIUM2026`, `VIPUSER`, `FREEUNLIMITED`, `TELEGRAM777`.

## 🚀 Быстрый запуск

### 1. Получите токен бота
1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и задайте имя и юзернейм для вашего бота.
3. Скопируйте полученный API токен (вид: `1234567890:ABCdef...`).

### 2. Укажите токен
Откройте файл `config.py` и вставьте ваш токен в строку:
```python
BOT_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
```
*(Либо сохраните его в переменной окружения `BOT_TOKEN`)*.

### 3. Запуск бота
- **Windows**: дважды кликните по `start.bat`, либо выполните в терминале:
  ```bash
  python bot.py
  ```

