# Umbra Studio — Сайт веб-студии

Современный лендинг с интерактивной анимацией, личным кабинетом, оформлением заказов, чатом поддержки и полноценной панелью администратора.

---

## 📁 Структура проекта

Код полностью разделен по стандартам веб-разработки (HTML, CSS, JS):

```
├── index.html                  # Главная разметка сайта и диалоговые окна
├── css/
│   ├── variables.css           # Цветовая палитра, токены и CSS-переменные
│   ├── animations.css          # Keyframes, фоновые эффекты, раскрытие при скролле
│   └── style.css               # Сетка, компоненты, формы, карточки, адаптив
├── js/
│   ├── utils.js                # База данных (localStorage), селекторы, хеширование, форматирование
│   ├── animations.js           # Звездное небо, параллакс, эффект печатной машинки, скролл-эффекты
│   ├── auth.js                 # Авторизация, регистрация, Turnstile-капча, проверка пароля
│   ├── orders.js               # Оформление заказов, валидация, окно «Мои заказы»
│   ├── chat.js                 # Виджет живого чата с ботом и быстрыми вопросами
│   ├── admin.js                # Панель управления (заказы, клиенты, портфолио, цены, баннеры)
│   └── main.js                 # Точка входа: инициализация и синхронизация всех модулей
└── README.md                   # Документация проекта
```

## ✨ Возможности и особенности

- **Анимации и эффекты:**
  - Генерация динамического звездного неба через `box-shadow`.
  - Эффект глубокой космической туманности (radial gradients) с параллаксом по движению мыши и скроллу.
  - Подсветка карточек (Spotlight), следующая за курсором.
  - Анимированная печатная машинка в Hero-секции.
  - Бегущая строка (Marquee) и появление блоков при прокрутке через `IntersectionObserver`.
  - Поддержка `prefers-reduced-motion` для пользователей, чувствительных к движению.

- **Функционал для клиентов:**
  - Оформление заказа с выбором тарифа или указанием своей суммы.
  - Быстрый выбор тарифа прямо из карточки с подсветкой формы.
  - Стильная кнопка «Войти» в навигационном баре с иконкой и плавным микро-эффектом.
  - Демо-авторизация и регистрация с защитой от перебора (SHA-256).
  - Просмотр своих оформленных заявок и их статусов в личном кабинете.
  - Интерактивный чат поддержки с автоответами по актуальным ценам и вызовом оператора.
  - Полный брендинг: интеграция единой иконки `favicon.png` в шапке, футере, чате и диалоговых окнах.
  - Развёрнутый FAQ из 10 ключевых вопросов о процессе, ценах, сроках, договоре и NDA.
  - Юридическая чистота: всплывающие окна «Политика конфиденциальности» (152-ФЗ), «Правила пользования» и «Политика cookie».
  - Плавающий баннер согласия с использованием cookie (Cookie Consent Banner) с фиксацией выбора в LocalStorage.

- **Личный кабинет и профиль клиента:**
  - Управление данными профиля: имя, телефон / Telegram, название компании или проекта.
  - Автоматическое предзаполнение контактных данных в форме оформления заказа для авторизованных клиентов.
  - Смена пароля с проверкой текущего пароля, индикатором надёжности и подтверждением (SHA-256).
  - Счётчик и быстрый переход к списку оформленных заказов клиента.
  - Удобный выход из аккаунта.

- **Админ-панель:**
  - Первый запуск на хостинге: при первом открытии через горячие клавиши `Ctrl + Shift + A` (или `Alt + A`), либо тройным кликом по копирайту в футере, система автоматически предложит задать собственный мастер-пароль администратора.
  - Управление заказами: смена статусов («Новый», «В работе», «Готов»), выставление стоимости проекта.
  - Управление клиентами: просмотр контактов, блокировка/разблокировка пользователей.
  - Портфолио: добавление работ с автоматическим сжатием изображений через HTML5 Canvas.
  - Управление ценами: изменение стоимости тарифов в реальном времени.
  - Управление баннером и приемом заказов (возможность приостановить приём заявок с объявлением).

## 🚀 Как запустить

- **Локально (без сервера):** просто дважды кликните на `index.html` — сайт полностью работоспособен из коробки в любом браузере.
- **Через локальный сервер:**
  ```bash
  # Python
  python -m http.server 8000
  
  # Node.js
  npx serve .
  ```
